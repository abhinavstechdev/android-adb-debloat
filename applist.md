## 6. Restoration & Management Reference

### To Restore Any Debloated App:
```bat
adb shell cmd package install-existing --user 0 <PACKAGE_NAME>
```

### To Uninstall Any Additional App for User 0:
```bat
adb shell pm uninstall -k --user 0 <PACKAGE_NAME>
```

### To Clear Cache for Any App:
```bat
adb shell pm trim-caches 200G internal
```
